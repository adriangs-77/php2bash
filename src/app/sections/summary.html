Un fallo del motor, no de tu aplicación

Cuando una petición muere de golpe (por ejemplo al agotar memory_limit), PHP no limpia todo su estado. El proceso reutilizado lo usa en la petición siguiente: eso permite leer memoria ajena y ejecutar código como el usuario web (www-data).
